🏫 CEM - App de Reclamações Escolares
Centro Educa Mais Prof. Maria Casimiro Soares - Bacabal / MA
App 100% gratuito, sem Play Store, para alunos fazerem reclamações de formaanônima, rápida e segura.
📱 Acesse o App
Link oficial:
https://91michellybraga-sys.github.io/cem-bacabal/
Escaneie o QR Code na porta da direção ou acesse o link acima.
✨ Funcionalidades
Para Alunos:
✅ Reclamação anônima ou identificada
✅ Categorias: Infraestrutura, Bullying, Professor, Merenda, Limpeza, Segurança
✅ Foto como prova, local e nível de urgência
✅ Protocolo de acompanhamento
✅ Funciona offline e instala como app
Para Direção:
🔐 Login seguro (senha padrão:
admin123
- altere em Configurações)
📊 Dashboard com gráficos por categoria e status
🔄 Mudar status: Recebida → Em Análise → Resolvida → Arquivada
💬 Responder oficialmente ao aluno
⚙️
Painel para mudar: nome da escola, cidade, logo, cores, senha e categorias
📥 Exportar para Excel (CSV)
🚀 Como instalar como App (sem Play Store)
1.
Abra o link no Chrome do celular
2.
Clique nos 3 pontinhos 􀀀 no canto superior
3.
Clique em
"Adicionar à tela inicial"
>
Instalar
4.
Pronto! O ícone com o logo da escola aparece na sua tela igual app de loja
🔧 Como mudar a senha da direção
1.
Entre como Direção no app
2.
Vá em
Configurações
(3ª aba)
3.
Preencha: Senha atual / Nova senha / Confirmar nova senha
4.
Clique em Salvar nova senha
🖨️
QR Code para mural
Imprima o cartaz com QR Code e cole nos murais, salas e porta da direção.
Os alunos escaneiam e já abrem o app.
